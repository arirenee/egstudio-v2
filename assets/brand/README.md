# EG Studio brand assets

Palette (light): Primary Navy #1B3A5C, Secondary Steel Blue #4A7FB5, Background #F4F6F8, Surface #FFFFFF, Text #1F2937, Muted #6B7280, Border #D8DEE5.

Dark mode (prefers-color-scheme): Background #0F1724, Surface #172133, Text #E9EEF4.

Icons and share-preview.png use outlined Montserrat ExtraBold glyphs, sourced from https://github.com/JulietaUla/Montserrat/blob/master/fonts/ttf/Montserrat-ExtraBold.ttf (SIL Open Font License). Outlines remove runtime font dependencies. Raster images were rendered from the same outlines with supersampling.

favicon.ico includes 16, 32 and 48 pixel PNG images. The 32/48 pixel standalone icons use EG for legibility. The 180 pixel Apple icon uses EG plus STUDIO. The social preview is 1200 by 630 pixels.
